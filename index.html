IDC 운영 자동화·시뮬레이션 포트폴리오

데이터센터·금융권 IT 인프라 운영 관점에서 반복 점검, 배치, 장애 대응, 백업, 변경관리, 보안, 네트워크 진단, Capacity/SLA 판단을 코드와 시뮬레이터로 구현했습니다.

운영 시뮬레이터

NOC

IDC 상면 관제

랙·장비·포트·환경 상태를 한 화면에서 확인합니다.

Batch

배치 운영·Control-M

선후행, 장애 전파, 재실행, SLA, Critical Path를 계산합니다.

Incident

IDC 장애 대응

조사→원인 판단→조치→보고 흐름을 시뮬레이션합니다.

Change

변경관리·Rollback

사전점검, 변경, 사후검증, Rollback 판단을 연습합니다.

Backup

백업 운영

스케줄, 복구체인, 매체/용량 장애를 다룹니다.

Server

서버 운영 콘솔

장애 상태와 Linux/Windows 명령 출력을 연동합니다.

Network

네트워크 경로 진단

DNS·방화벽·L4·라우팅·MTU 문제를 구간별로 좁힙니다.

Security

Linux 보안 실습

권한, 로그 판별, 방화벽 요청 검토를 실습합니다.

운영 자동화 도구

Python

Server Health Check

healthcheck.py — CPU·메모리·디스크·서비스·네트워크 상태와 종료 코드.

Python

Log / Alert

log_analyzer.py + alert_correlator.py — 급증 탐지와 다중 알람 Incident 상관분석.

Python

Capacity / SLA

capacity_planner.py + sla_calculator.py — 자원 임계 도달과 허용 장애시간 계산.

Python

Backup / Certificate

backup_verify.py + cert_expiry.py — 복구 가능성 및 인증서 만료 사전 점검.

Python

Incident Report

incident_report.py — 장애 타임라인, 조치, 후속 확인, 교대 인수인계 Markdown 생성.

CI

Repository Verification

review_repo.py, run_analyze.py, execute_repo.py, unittest, Dependabot을 연결합니다.

GitHub Actions에서 전체 functional 실행과 단위 테스트를 다시 수행할 수 있습니다.
